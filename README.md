# ❄️ Snowflake Learning Repository

A comprehensive repository for learning **Snowflake Data Cloud** from fundamentals to advanced concepts. This repository contains SQL scripts, hands-on examples, best practices, interview-focused topics, and real-world use cases to help data engineers, analysts, and cloud professionals master Snowflake.

## 📚 Topics Covered

### 1. Snowflake Fundamentals
- Snowflake Architecture
- Databases, Schemas, and Tables
- Virtual Warehouses
- Roles and Access Control
- Snowflake Editions

### 2. SQL & Data Manipulation
- DDL Commands
- DML Commands
- Constraints
- Joins
- CTEs
- Subqueries
- Window Functions
- Set Operators

### 3. Data Loading & Unloading
- Internal Stages
- External Stages
- File Formats
- COPY Commands
- Data Export

### 4. Snowflake Advanced Features
- Time Travel
- Fail-safe
- Zero-Copy Cloning
- Streams
- Tasks
- Snowpipe
- Materialized Views

### 5. Semi-Structured Data
- JSON Processing
- VARIANT Data Type
- FLATTEN Function
- XML and AVRO Support

### 6. Security & Governance
- RBAC (Role-Based Access Control)
- Data Masking
- Row Access Policies
- Network Policies
- Secure Views

### 7. Performance Optimization
- Query Profiling
- Clustering Keys
- Caching Mechanisms
- Warehouse Sizing
- Cost Optimization

### 8. Snowflake Interview Preparation
- Frequently Asked Interview Questions
- Scenario-Based Questions
- Architecture Discussions
- Best Practices
